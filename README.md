# Revenue Retention dashboard (demo)

A single-file dashboard (`index.html`) showing net revenue retention, gross revenue
retention, churn rate, upsell dollars and upsell percentage, overall and broken down by
account manager, stage (Enterprise, Mid Market, Scale Up, Startup) and industry.

**All data is fictional.** Accounts, account managers and figures are generated in the
browser from a fixed random seed, so the numbers are the same on every load. No real
employees or customers appear anywhere.

Open `index.html` in a browser, or serve the folder with any static host. There is no
build step and no dependencies beyond an optional Google Font.

Metric definitions are listed at the bottom of the page.
